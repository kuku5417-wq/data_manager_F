# ============================================================
#  시운전팀 사내 앱 접속 별칭 (hosts 샘플)
# ============================================================
#  목적: 사내망에서 PC IP로 접속하면 회사 프록시를 타서 "프록시 점검" 오류가 남.
#        아래처럼 "점 없는 단일 이름" 별칭을 만들면 보통 프록시를 우회(직결)하여 정상 접속됨.
#
#  적용 위치(접속하는 각 PC):
#    C:\Windows\System32\drivers\etc\hosts
#    - 메모장을 "관리자 권한"으로 실행 → 위 파일 열기(모든 파일 표시) → 맨 아래에 추가 → 저장
#    - 저장 후 cmd:  ipconfig /flushdns
#    - 확인:        ping ocr   (지정한 IP로 응답하면 성공)
#
#  주의:
#    - hosts 는 "이름 -> IP" 만 매핑함. 포트는 URL 에 직접 붙임 (예: http://ocr:8520)
#    - 별칭 이름은 임의(앱과 무관). 앱 구분은 "포트"로 함.
#    - 아래 IP(10.0.0.50)를 "앱이 실행 중인 호스트 PC의 실제 IP"로 바꿀 것 (cmd: ipconfig)
# ============================================================

# [경우 1] 모든 앱이 한 대의 공용PC에서 도는 경우 — IP 한 개, 별칭 한 줄
10.0.0.50    dm  tbm  esg  ocr  esgm  tbmm  cost

# [경우 2] 앱마다 다른 PC에서 도는 경우 — 호스트별로 줄 분리(필요한 것만)
# 10.0.0.50   dm           # data_manager 호스트
# 10.0.0.51   esg          # esg 호스트
# 10.0.0.52   ocr          # ocr 호스트
# 10.0.0.53   tbm          # tbm 호스트

# ------------------------------------------------------------
#  별칭 -> 접속 주소 (포트는 앱마다 고정)
# ------------------------------------------------------------
#    data_manager   http://dm:8510
#    tbm            http://tbm:8502
#    esg            http://esg:8503
#    ocr            http://ocr:8520
#    esg_mssql      http://esgm:8513
#    tbm_mssql      http://tbmm:8512
#    costplan       http://cost:8530
# ------------------------------------------------------------
#  (호스트 PC 본인은 http://localhost:<포트> 로 접속 — 기본 우회)
#  (가장 깔끔한 방법: 회사 IT 에 DNS 별칭(CNAME) 등록 요청 → 모든 PC 자동 적용)
